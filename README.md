# 🚀 GitStats Hub

A modern and responsive **GitHub Profile Finder** built using **HTML, CSS, and JavaScript**. Search any GitHub username and instantly explore profile details, repository statistics, language usage, and more through a clean developer-focused dashboard.

## ✨ Features

* 🔍 Search GitHub profiles
* 👤 View avatar, bio, followers, following, and repositories
* 🌙 Dark & ☀️ Light mode support
* ⭐ Top 5 repositories by stars
* 📊 Language distribution analysis
* 📁 Recent repositories section
* 📋 Copy GitHub profile URL
* 🕒 Search history with local storage
* ⚡ Loading animations and error handling
* 📱 Fully responsive design

## 🛠️ Technologies Used

* 🌐 HTML5
* 🎨 CSS3
* ⚙️ JavaScript (ES6+)
* 🐙 GitHub REST API

## 🚀 Getting Started

```bash
git clone https://github.com/Guru-codes07/GitStats-Hub.git
cd GitStats-Hub
```

Open `index.html` in your browser or run a local development server.
